00

先回答：这个算子为什么这么重要？

讲解 1 min

一句话：Attention 是几乎所有现代大模型（GPT / LLaMA / Claude / 文生图、文生视频）的共同骨架。掌握它，等于拿到理解整个生成式 AI 的钥匙。

它能做什么

让序列中每一个位置同时看到所有其他位置，决定"该把注意力分给谁"——这就是名字 Attention（注意力）的由来。

为什么取代了 RNN

没有"必须从头算到尾"的依赖链，天然可并行，于是能堆上千层、吃海量数据，撑起超大规模训练。

算子视角：Attention 的核心就是三个矩阵乘法 + 一个 softmax。整堂课的目标，就是让你在脑子里把这句话"可视化"出来。

02

从 RNN 的痛点说起

讲解 1 min

在 Attention 之前，处理"一串词"的主力是 RNN。它最大的毛病：只能一个一个往后算，算不出第 4 个就得等前 3 个——无法并行，GPU 干着急。

图 1 / 对应 PDF 图 1·2·3 — 处理序列数据的两种范式
Self-Attention 的输入输出和 RNN 一模一样（序列进、序列出），区别只在于：每个输出 $b_i$ 都并行地看过了整条序列。
03

Self-Attention · 向量级（一步一步算）

讲解 3 min
Query 查询：我想找什么 Key 键：我有什么可被匹配 Value 值：匹配上后实际拿走的内容

这是整堂课的核心一张图。我们以"算出第 1 个输出 $b_1$"为例，分 4 步走。先记住三个词：每个输入词 $x$ 会变成三份不同身份——Q（去问别人）、K（被别人问）、V（真正的内容）。

图 2 / 对应 PDF 图 4–9 — 用 q₁ 计算出 b₁ 的完整 4 步（b₂ b₃ b₄ 同理并行）
① 每个词 $x$ 乘三个可学习矩阵 $W^q, W^k, W^v$，得到它自己的 q/k/v（"身份三件套"）。
② 拿 $q_1$ 去和所有人的 $k$ 做点积，得到"相关度分数" $\alpha_{1,j}$——越像分数越高。
③ 对这一串分数过 softmax，变成加起来等于 1 的权重 $\hat\alpha$（这就是"注意力分配"）。
④ 用权重去加权所有人的 $v$，求和，得到融合了全局信息的输出 $b_1$。
关键直觉：Q 和 K 负责"决定该关注谁"，V 负责"被关注后拿走的内容"。点积大 = 两个词语义相关 = 权重大 = b 里这部分 v 的占比高。
04

Self-Attention · 矩阵级（三步搞定）

讲解 2 min

上一节我们是一个向量一个向量地算。如果把所有词的 q/k/v 堆成矩阵 $Q, K, V$，整件事就坍缩成三次矩阵乘法——这正是 GPU 最擅长、能大规模并行的形态。

图 3 / 对应 PDF 图 10–12 — 把向量级推导压成"一堆矩阵乘法"，于是能用 GPU 加速
$$\text{Attention}(Q,K,V) = \mathrm{softmax}\!\left(\frac{QK^{\mathsf{T}}}{\sqrt{d_k}}\right)V$$
看，这就是论文里那句著名的公式。现在它对你不再是一串符号：$QK^{\mathsf T}$ 是"两两算相关度"，softmax 是"把分数变成权重"，乘 $V$ 是"按权重取出内容"。下面我们补上中间多出来的那个 $\sqrt{d_k}$。
05

那个 $\sqrt{d_k}$ 是干嘛的？

讲解 1 min

公式里多了一个"除以 $\sqrt{d_k}$"，叫缩放（Scale）。原因一句话：维度 $d_k$ 越大，点积 $QK^{\mathsf T}$ 的数值就越大，softmax 会被推向极端（一个 1、其余 0），梯度消失，训不动。

不缩放会怎样

点积是 $d_k$ 个乘积之和。$d_k$ 大 → 点积方差大 → softmax 输出几乎是 one-hot → 梯度接近 0 → 训练停滞。

除以 $\sqrt{d_k}$ 的效果

把点积的方差拉回 1 附近，让 softmax 处在"温和"的区间，梯度健康。这是算子实现里最容易被漏掉、但必须有的细节。

06

多头注意力（Multi-Head）

讲解 3 min

只做一次 attention，模型只能学到"一种关注方式"。把它拆成多个头（head），各自独立算 attention，等于让模型从多个角度（语法、长程、局部……）同时看序列，最后拼回来。

图 4 / 对应 PDF 图 13–15 — 多个头并行算注意力，拼接后经 Wᴼ 映射回原维度

不同头学到了不同的关注方式

下面是三个头的注意力权重热力图（行=Query 词，列=Key 词，颜色越亮权重越大）。切换标签可以看到：有的头盯着主对角线（局部），有的头跨很远（长程），有的头几乎平均（全局）。可点击切换

Head 2 · 局部
Head h · 全局
Head 1：权重大量出现在非对角线位置 → 擅长捕捉长距离依赖
实践要点：每个头把维度 $d$ 切成 $d/h$，所以总计算量和单头接近，但表达能力更强。这就是"几乎免费获得多视角"。

经典 Transformer 全景图（论文 Figure 1）

把 Attention 装进完整模型长什么样？这就是原论文那张被引用了几万次的结构图——左 Encoder（编码器）、右 Decoder（解码器），各堆叠 N 层。我们逐块拆。

图 5 / 对应论文 Figure 1（PDF 图 21·28·34）— Attention 是其中反复出现的核心积木

Decoder：先用 Masked Self-Attention（屏蔽未来位，防止作弊），再通过 Cross-Attention 去"读取"编码器的 K/V，最后预测下一个词。
注意：这张图里 Attention 出现了三次（Encoder 自注意、Decoder 掩码自注意、Decoder 交叉注意）。我们前面学的那个公式，是这三处共用的同一个算子——这就是它"为什么重要"的最终答案。
08

补一块拼图：位置编码

讲解 1 min

Self-Attention 对"顺序"是无感的——"我打他"和"他打我"算出来一样。所以在输入 embedding 上直接加一个位置向量，把顺序信息喂回去。

$$PE_{(pos,\,2i)} = \sin\!\left(\frac{pos}{10000^{2i/d_{\text{model}}}}\right),\quad PE_{(pos,\,2i+1)} = \cos\!\left(\frac{pos}{10000^{2i/d_{\text{model}}}}\right)$$
用不同频率的正余弦，让每个位置拿到唯一的编码；并且对任意固定间距 $k$，$PE_{pos+k}$ 是 $PE_{pos}$ 的线性函数——模型因此能泛化到比训练更长的序列。
09

经典代码（the Annotated Transformer）+ 算子测试要点

讲解 2 min

原理看懂了，落到代码就几十行。下面是哈佛 The Annotated Transformer 的经典实现，逐行对应我们讲过的步骤。

① 缩放点积注意力 —— 对应公式 $\mathrm{softmax}(QK^\mathsf{T}/\sqrt{d_k})V$
def attention(query, key, value, mask=None):
    # query/key/value: (batch, heads, seq, d_k)
    d_k = query.size(-1)
    scores = torch.matmul(query, key.transpose(-2, -1)) / math.sqrt(d_k)  # ① QKᵀ 再缩放
    if mask is not None:
        scores = scores.masked_fill(mask == 0, -1e9)        # ② 屏蔽不该看的位置
    p_attn = scores.softmax(dim=-1)                        # ③ softmax → 权重
    return torch.matmul(p_attn, value), p_attn              # ④ 权重 × V
② 多头注意力 —— 对应图 4 的分头、拼接、Wᴼ 映射
class MultiHeadedAttention(nn.Module):
    def __init__(self, h, d_model, dropout=0.1):
        assert d_model % h == 0                 # d_model 必须能被头数整除
        self.d_k = d_model // h                 # 每个头分到的维度
        self.h = h
        self.linears = clones(nn.Linear(d_model, d_model), 4)  # Wᵠ Wᵏ Wᵛ Wᴼ

    def forward(self, query, key, value, mask=None):
        if mask is not None: mask = mask.unsqueeze(1)
        nbatches = query.size(0)
        # 1) 线性映射 + 拆头: (b, seq, d_model) → (b, h, seq, d_k)
        query, key, value = [
            l(x).view(nbatches, -1, self.h, self.d_k).transpose(1, 2)
            for l, x in zip(self.linears, (query, key, value))
        ]
        # 2) 在每个头上算 attention
        x, self.attn = attention(query, key, value, mask=mask)
        # 3) 拼头: (b, h, seq, d_k) → (b, seq, d_model)
        x = x.transpose(1, 2).contiguous().view(nbatches, -1, self.h * self.d_k)
        # 4) 最后过 Wᴔ
        return self.linears[-1](x)

算子测试要点（leader 关心的）

数值正确性

用小矩阵手算 softmax(QKᵀ/√dk)V，和算子输出逐元素比对；验证每行之和=1、padding 位置权重≈0。

形状与边界

校验 $(B,h,n,d_k)$ 各维变换；测试 $d_k$ 不能被头数整除时报错、空序列、单 token、因果 mask 下三角等边界。

mask 正确性

Decoder 的因果 mask 必须严格下三角；被屏蔽位置 softmax 后应为 0，输出不受未来 token 影响。

性能与精度

对比 fp32/fp16/bf16 的相对误差（通常 <1e-3）；记录显存与耗时随 seq、heads、d_k 的变化曲线。

一句话总结整堂课：Attention 把"序列中每个位置该关注谁"这件事，变成了 $QK^\mathsf T\!/\sqrt{d_k}$ 算分、softmax 变权重、再乘 $V$ 取内容——三步矩阵乘法。多头扩展视角，加上位置编码补顺序，组装成 Encoder/Decoder，就是撑起所有现代大模型的 Transformer。
